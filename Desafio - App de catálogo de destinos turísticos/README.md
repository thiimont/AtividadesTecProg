# Aplicativo de catálogo de destinos turísticos

O repositório contém o MVP de um aplicativo de catálogo de destinos turísticos. Cada destino cadastrado deve ter um link para uma página web de referência (Wikipedia, TripAdvisor, site oficial, etc.) que o usuário poderá visualizar diretamente dentro do aplicativo por meio de um WebView, sem sair do app.

Desenvolvido em conjunto com meu amigo <a href="https://www.linkedin.com/in/guilherme-cau%C3%A3-soares/">Guilherme Cauã Soares</a> na aula de Programação para Dispositivos Móveis I, em um desafio proposto pelo professor Alessandro Lima.
