# Aplicativo de lista de filmes/séries com Firebase Auth e Room

O repositório contém um aplicativo onde você pode registrar filmes e séries, marcar como assistido e também adicionar um link para o filme/série. O aplicativo conta com um login (sem registro) com Firebase Auth e utiliza Room para salvar os dados do filme/série localmente. A versão sem o login com Firebase pode ser encontrada [aqui](https://github.com/thiishy/Movlist).
